# Family Happy Mario

A family browser game with the same deploy style as `family-happy-game`.

## Play

Open `index.html` directly, or run a local server:

```sh
python3 -m http.server
```

Then open:

```text
http://localhost:8000
```

## Theme

- Two-side platformer progression.
- Characters: Aiden, Dean, Jake, Kash, and Riggs.
- Enemies: spiders with duck heads.
- End-of-level 1 has a flag pole.
- End-of-level 2 is Uncle Brian in a dark-grey Nissan Frontier truck.
- Football-field background inspired by Dunmore, Pennsylvania.
